# Writeups agent rules

- Read PLAN.md first; TC24 PLAN owns programme order and experiment admission.
- Preserve historical writeups and attribution. A collected draft is not checked theory.
- Shared basic theory/independent validation belongs in kin6d; native derivations stay with own codes. This repository owns readable companions and externally maintained third-party correspondence.
- No FortSym files or dependency are inserted into third-party solver repositories. Pin external code commits, routine paths, mode predicates and conventions here.
- Keep provenance, conditions and code/literature differences. Distinguish symbolic identities, probes, historical results and unresolved claims.
- Upload new plots and rendered writeup PDFs to slopbox; never commit generated plots/PDFs. Retain source, scripts, input/numerical data, hashes and artifact URL manifests for reproduction.
- Keep local archive receipts under ignored .local/. Import source material only with established authorship/redistribution terms; preserve file-specific notices. Source inventories do not confer a new license.
- Workers return exact-base patch evidence; controller owns integration and promotion. Preserve unrelated edits and stage explicit paths.
